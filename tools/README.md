External engines are installed here by `scripts\Setup-Tools.ps1`.

Required executables: `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe`, `deno.exe` (Windows x64).

The Visual Studio application target copies installed engines and metadata into its output's `tools` subfolder. Alternatively, select this directory with **Tools folder…**. Tool binaries are excluded from the source archive and version control.
